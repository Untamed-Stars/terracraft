# 🌍 TerraCraft

**Build your world, one block at a time.**

TerraCraft is a browser-based voxel sandbox inspired by Minecraft, developed using JavaScript and Three.js. Explore a procedurally generated world, interact with individual blocks, and reshape the environment around you.

The project focuses on creating an accessible 3D sandbox experience that runs directly in a web browser. Players can jump into the world without downloading additional files or installing a separate application.

TerraCraft is an independent project currently under active development by **Untamed Stars**.

---

## 🎮 Play TerraCraft

TerraCraft is hosted on GitHub Pages, allowing players to access the game directly through their web browser.

- **Platform:** Web browser
- **Installation:** Not required
- **Downloads:** Not required
- **Rendering:** Real-time 3D graphics

A modern browser with support for JavaScript modules and WebGL is recommended for the best experience.

## ✨ Current Features

### 🌱 Procedural World Generation

TerraCraft generates block-based terrain programmatically, creating a world made up of individual voxel cubes. Terrain elevation and natural features help give the environment its own landscape.

### 🌳 Natural Environment

Trees and other terrain features add variety to the generated world, making the environment more than a flat collection of blocks.

### 🧭 First-Person Exploration

Explore the world from a first-person perspective. Mouse look allows you to examine your surroundings, while movement and jumping let you navigate the terrain.

### ⛏️ Block Interaction

The world is designed to be modified by the player.

- **Break blocks** to remove parts of the environment.
- **Place blocks** to build and reshape the world.
- **Select blocks** through the hotbar to interact with different materials.

These mechanics form the foundation for a more extensive building and exploration experience.

### 🎒 Hotbar and HUD

The in-game hotbar provides access to available block types, while the heads-up display (HUD) presents gameplay interface elements.

Together, these systems help make block selection and world interaction accessible during gameplay.

### 🧱 Voxel-Based Graphics

The environment is constructed from cubic blocks, following the recognisable visual language of voxel sandbox games. Different block types use distinct appearances to help the world feel varied and readable.

## 🕹️ Controls

The current control scheme uses keyboard and mouse input.

| Input | Action |
|---|---|
| W | Move forward |
| A | Move left |
| S | Move backward |
| D | Move right |
| Mouse | Look around |
| Space | Jump |
| Mouse buttons | Break and place blocks |
| Hotbar controls | Select blocks |

*Controls may change as development progresses.*

## 🛠️ Technology

TerraCraft is built using standard web technologies and a browser-based 3D rendering library.

| Technology | Purpose |
|---|---|
| HTML | Page structure and game interface |
| CSS | Styling and interface layout |
| JavaScript | Gameplay logic and world systems |
| Three.js r180 | 3D rendering, scene management, and graphics |
| GitHub Pages | Website hosting |

Three.js allows TerraCraft to render and display its 3D world without requiring a separate game engine installation on the player's device.

## 🚀 Future Development

TerraCraft is actively being developed, and its current systems provide the foundation for future improvements.

### 🌞 Lighting and Shadows

The lighting system is a planned area of improvement. Future work may include more balanced sunlight, more natural shading across block faces, and lighting that responds to the surrounding environment.

### 💡 Block-Based Lighting

A more advanced lighting system could allow sunlight to propagate through open spaces while being blocked by solid terrain. Enclosed areas could become darker, and breaking blocks could allow light to enter previously shaded spaces.

### 🪨 Expanded Block Types

Additional block types could expand the range of materials available for building and world interaction, giving players more options when modifying their surroundings.

### 🌎 World Generation Improvements

Further development may introduce more varied terrain, additional environmental features, and improvements to the procedural generation system.

### 🌐 Multiplayer

Multiplayer is a potential long-term goal. This could allow multiple players to explore the same world, build together, and see changes made by other players.

*Future features are exploratory plans and are not guaranteed to be included in a particular release.*

## 📍 Development Status

The project is being developed incrementally, with new systems introduced and tested as development continues.
