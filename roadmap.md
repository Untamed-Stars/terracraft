# 🌍 TerraCraft Development Roadmap

**Build your world, one block at a time.**

A living development plan for TerraCraft, a browser-based voxel sandbox developed by Untamed Stars.

---

## 🌱 Phase 1: Core Foundations

Establish the core sandbox experience and make sure the existing mechanics work reliably.

- [x] First-person movement and mouse look
- [x] Jumping
- [x] Procedural terrain and trees
- [x] Block breaking and placement
- [x] Hotbar and HUD
- [x] Grass textures
- [x] Dirt texture
- [x] Stone texture
- [ ] Sand texture
- [ ] Wood texture
- [ ] Test and polish existing gameplay systems

## 🌞 Phase 2: Lighting and Visuals

Improve the appearance of the world and create more natural lighting.

- [ ] Balance sunlight and shaded block faces
- [ ] Prevent textures from appearing excessively bright
- [ ] Implement sunlight blocking by solid blocks
- [ ] Add light propagation through open spaces
- [ ] Update lighting when blocks are placed or broken
- [ ] Explore ambient occlusion and improved shadows

## 🪨 Phase 3: World Expansion

Expand the building and exploration experience with additional blocks and environmental variety.

- [ ] Introduce additional block types
- [ ] Expand terrain variety
- [ ] Improve procedural world generation
- [ ] Add more environmental details
- [ ] Refine block selection and inventory systems
- [ ] Improve performance as the world grows

## 🛠️ Phase 4: Gameplay Improvements

Refine the existing mechanics and make TerraCraft more enjoyable to play.

- [ ] Refine movement and collision
- [ ] Improve the hotbar and player interface
- [ ] Add more building and interaction options
- [ ] Improve world loading and stability
- [ ] Test across different browsers and screen sizes

## 🌐 Phase 5: Multiplayer

Explore the possibility of shared worlds once the single-player foundation is stable.

- [ ] Investigate server and WebSocket architecture
- [ ] Synchronise player positions between clients
- [ ] Synchronise block placement and breaking
- [ ] Support multiple players in a shared world
- [ ] Test connection handling and world consistency

## 📍 Development Status

TerraCraft is a work in progress. Development is focused on building a reliable single-player foundation, improving the visual presentation, and expanding the world before tackling more complex systems.

The roadmap is flexible. Priorities and features may change as development continues.
